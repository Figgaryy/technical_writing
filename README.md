# GTS302 Final Templates

Study page for the GTS302 Technical Writing written final. It covers recommendation reports, proposals, instructions and investigative reports, with fill-in sentence frames, annotated model answers, Part 1 revise drills and a checklist.

Open `index.html` in a browser, or enable GitHub Pages on the `main` branch.

The model answers were written for practice. They are not the lecturer's answer key.
